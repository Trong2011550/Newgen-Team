# 3. Hệ thống Language

Tạo thư mục

lang/

Bao gồm

vi_VN.yml

en_US.yml

Trong config.yml

language: vi_VN

hoặc

language: en_US

Plugin sẽ tự load file ngôn ngữ tương ứng.

Không hardcode bất kỳ text nào trong code.

Toàn bộ:

* Chat
* GUI
* ActionBar
* BossBar
* Title
* Command Message
* Error
* Success
* Placeholder Text

đều phải lấy từ language file.

Nếu thiếu key thì fallback sang en_US.
